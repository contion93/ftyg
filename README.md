# 饭太硬改

本仓库仅用于临时存放TVBox需要的一些静态资源，所有内容均来源于 [饭太硬](http://www.饭太硬.net/tv) 和 [simlive](https://simlive.github.io/tvlogo/) 。这里不储存任何视频文件，不对外公开提供任何服务。本文仅用于备忘。

## 修改

对原版饭太硬做了部分仅适用于本人的修改。
1. 隐藏了所有网盘和一些本地无法连接的地址，以及部分会污染搜索结果的项；
2. 修改了直播源的部分属性，集成了部分台标文件。
